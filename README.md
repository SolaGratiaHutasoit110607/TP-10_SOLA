# Character Manager v0.5

Aplikasi desktop berbasis Java Swing untuk menampilkan dan mengelola informasi karakter.

## Teknologi
- Java
- Java Swing
- Visual Studio Code

## Fitur
- Menampilkan daftar karakter.
- Menampilkan nama, role, level, HP, dan ATK.
- Menampilkan legenda role.
- Menggunakan Scroll Pane.
- Tampilan responsif dengan Layout Manager.

## Struktur Package
- `model` : Mengelola data karakter.
- `view` : Mengatur tampilan aplikasi.

## Layout Manager
- BorderLayout
- GridLayout
- BoxLayout
- FlowLayout
